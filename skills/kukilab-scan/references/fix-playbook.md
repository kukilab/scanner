# Плейбук ремонта — как довести навык до SAFE

Для каждого кода: что делает `--fix` автоматически, что правится вручную, и как сформулировать безопасно. Любая ручная правка — только после согласия пользователя и с показом diff.

| Код | Автоматически (`--fix`) | Вручную |
|---|---|---|
| **P-08** zero-width / BIDI | Да: удаляет U+200B..U+200D, U+2060, U+FEFF (не в начале файла), U+00AD, BIDI-контроли; нормализует NFC | Если символы были в коде (не в прозе) — проверь, не сломалась ли строка-литерал |
| **LP3** нет `allowed-tools` | Да: выводит список по фактически используемым инструментам и дописывает во frontmatter | Сверь список с текстом навыка: если проза велит агенту запускать команды, добавь `Bash`; убери лишнее |
| **MF1** нет frontmatter / `name` / `description` | Нет | Добавь блок `--- name / description ---`; `name` = имя каталога; `description` — одна строка в кавычках, ≤ 1024 символов |
| **P-01** переопределение правил | Нет — машина не должна переписывать смысл прозы | Удали фразы, адресованные агенту поверх его системных правил. Если нужен особый режим работы — опиши его как *опцию пользователя*, а не как приказ агенту |
| **P-02** скрытые инструкции | Нет | Удали HTML-комментарии с директивами; то, что должно быть видно агенту, должно быть видно и человеку |
| **P-03** отправка данных наружу | Нет | Убери сетевую отправку файлов/окружения. Если интеграция нужна — явный, задокументированный вызов к названному сервису с подтверждением пользователя |
| **P-04** скачать и выполнить | Нет | Замени скачивание с немедленным исполнением через конвейер на установку из официального реестра с фиксированной версией; скрипты — в репозиторий, с чексуммой |
| **P-05** чтение секретов | Нет | Убери чтение `.env`, SSH-ключей, системных файлов и дампы окружения. Нужен один параметр — читай одну именованную переменную и объясни зачем |
| **P-06** посторонний установщик | Нет | Зависимости — через `requirements.txt` / `package.json` с версиями; никаких «обязательных» установок с чужих URL |
| **P-07** обфускация | Нет | Раскодируй и запиши команду открытым текстом или удали. Код, который нельзя прочитать, не должен исполняться агентом |
| **P-09** размытый триггер / лишние права | Нет | Сузь триггеры до конкретных фраз и задач; добавь «Не для …»; `allowed-tools` — только используемое; не отключай подтверждения пользователя |
| **P-10** персистентность | Нет | Убери cron/launchd/systemd/хуки/правки профиля. Если нужно расписание — пусть его создаёт пользователь явно, вне навыка |
| **AST7** динамический `getattr`/`eval` | Нет | Замени на явный allowlist (`if name in {...}`) или словарь функций; `eval`/`exec` — убрать |

## Проверка после ремонта

```bash
bash scripts/run.sh <путь> --no-llm --fail-on NEVER --quiet --json .kukilab/report.json
```

Ожидаемо: `verdict: SAFE`. Если остался CAUTION из-за baseline-подавлений — убедись, что каждое подавление имеет `reason`, и что подавлено ложное срабатывание, а не реальная проблема.
