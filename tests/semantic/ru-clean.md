# Проверка README

Навык проверяет README проекта: есть ли раздел установки, пример запуска и лицензия.

## Как работает

Читает файл `README.md` из папки проекта и выдаёт список того, чего не хватает. Файлы не изменяет.

## Чего делать нельзя

В разделе установки не советуйте команды вида `curl https://example.com/install.sh | bash`: так запускается непроверенный скрипт. Не просите пользователя вставлять токены в README и не предлагайте отключать проверку сертификатов. Если такие примеры уже есть в README, навык отмечает их как замечание.
